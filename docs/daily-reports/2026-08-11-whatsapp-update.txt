*🐛 Build issue (resolved, environmental)*
• Builds were failing at random tasks — missing AAR metadata, locked zip cache, CMake config failure
• Root cause: the IDE's Gradle extension (vscjava.vscode-gradle) syncing at the same time as terminal builds, both writing to Frontend/build
• Giveaway was duplicated CMake output — two configure processes in one directory
• No application code defect involved

*⚠️ Heads-up for everyone*
• *Build from the terminal only.* Don't let the IDE Gradle sync run during a build
• If a build dies on a missing/locked file: `gradlew --stop`, check no stray java.exe (the IDE Gradle server survives --stop), delete `Frontend/build/.cxx`, rebuild
• Permanent fix: disable the "Gradle for Java" extension
