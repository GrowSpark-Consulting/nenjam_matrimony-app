### The single most important structural finding

The backend has **18 module directories** under `backend/apps/api/src/modules/`, but only **12 are imported into `AppModule`** (`backend/apps/api/src/app.module.ts`).

The six that are **not** wired — `admin`, `astro`, `search`, `subscription`, `trust-score`, `verification` — consist entirely of **4-line stub files**:

```ts
import { Controller } from '@nestjs/common';

@Controller()
export class VerificationController {}
```

That one fact accounts for **Aadhaar verification, face verification, horoscope/Prokerala, Razorpay/premium, trust score, Elasticsearch search, and the admin panel** simultaneously.
